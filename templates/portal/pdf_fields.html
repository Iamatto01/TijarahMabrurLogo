How it works

Each field writes text onto the PDF at position (x, y) on a given page. Coordinates are in PDF points (1 point = 1/72 inch), origin at the bottom-left of the page.

Example field:

{
  "name": "company_name",
  "label": "Company Name",
  "page": 1,
  "x": 150,
  "y": 660,
  "size": 11
}

Tips

  • A4 page is about 595 × 842 points.
  • name = form field key (no spaces), label = what the user sees.
  • Fill & export once with test values, open the PDF, then nudge x/y until the text lands on the right lines.
  • Multi-line values work — text flows downward from y.
